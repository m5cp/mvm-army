LINKAGE RULES — NO FALSE RESULTS
1 · Profile is a single source of truth: (sex, ageGroup, standard) lives in one state object; every event's points derive from it — never cached per-event.

2 · Any profile change triggers a full re-score of all five raw inputs through your existing scoring engine. Points are never stored, only raw values.

3 · Combat standard → engine receives sex-neutral table key; the sex toggle stays enabled (it's recorded on the scorecard) but visibly notes it doesn't change combat scoring.

4 · Total, PASS/FAIL, and the min-line marker all recompute in the same pass — one render, no intermediate states.

5 · Saved results store the full profile with the raw inputs, so history never re-scores under a different profile.
